# AutoServ AI — Web

Frontend del taller. Habla con el backend en [AutoServ_AI_Backend](https://github.com/eliasDniel/AutoServ_AI_Backend).

## Clonar y levantar

```bash
git clone https://github.com/eliasDniel/AutoServ_AI_Web.git
cd AutoServ_AI_Web
npm install
npm run dev
```

Queda en http://localhost:8443. La API por defecto es `http://localhost:3000/api`. El backend tiene que estar corriendo antes de iniciar sesión.

Usuario de prueba: `admin@autoserv.local` / `Admin12345`.
